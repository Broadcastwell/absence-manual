# Is there a print edition of our research?

Yes. The print edition of Study 1, The Shortlist Gap, is a free 22-page PDF on US Letter paper: one cover sheet with the citation, print settings and the original file's checksum, followed by the unchanged 21-page report of 26 September 2026. Print it at home or at any print shop. This page and our research report list also print cleanly.

The study counts which of 286 checked software vendors ChatGPT, Claude, Perplexity, Google AI Overviews and Google AI Mode named in 2,095 valid answers to 140 buyer questions, captured 22 to 23 September 2026. Its first page reports that 46 of the 286 vendors, 16.1 percent (95 percent interval 12.3 to 20.8 percent), were never named.

## How the edition was made, and how to check it

We placed one new cover sheet in front of the published report and changed nothing else. Every report page carries the same page content as the [original PDF](assets/research/study1/Study1_The_Shortlist_Gap_2026-09.pdf), and the file has two bookmarks, one for the cover and one for the report.

To check it yourself:

1. Open the edition and confirm it has 22 pages and that page 2 is the report's first page.
2. Download the original report and compute its SHA-256 value; it should match the value printed on the cover sheet and in the table above.
3. Compare any page of the edition with the same page of the original, one page later in the edition.

The [checksum list](assets/research/print/research-report-sha256.txt) records the SHA-256 value of the edition file itself as well.

## Print settings

- **Scale:** actual size, 100 percent. Fit-to-page scaling shrinks the text.
- **Sides:** two-sided, flip on the long edge. The 22 pages print on 11 sheets.
- **Order:** keep the cover sheet first, so the citation and checksum stay with the copy.
