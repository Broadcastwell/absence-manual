# Content strategy template

One strategy per category and period, built on a frozen question set and a dated baseline.

| Field | What to enter | Value |
| --- | --- | --- |
| Period | The months this strategy covers. |  |
| Category, in the buyer's words | How buyers name the category. |  |
| Question set | Count and groups, agreed and frozen before capture. |  |
| Engines | Each engine by name. |  |
| Baseline | Capture dates, scheduled runs, valid answers and exclusions. |  |
| Named today | Your named count with its base and 95 percent interval. |  |
| Questions with an appearance | Questions where at least one answer named you. |  |
| Most named rival | The rival named most, with its count and base. |  |
| Own pages cited | Answers citing your domain, with the base. |  |
| Sources cited most | Outside domains cited most, each with its count and base. |  |
| Priority 1 | Question, action, owner and status. |  |
| Priority 2 | Question, action, owner and status. |  |
| Priority 3 | Question, action, owner and status. |  |
| Measurement plan | Which runs compare with the baseline, and how a change is called. |  |
| Latest change | The latest separated change, with both counts and bases. |  |
| Provider releases between captures | Marks from the model release tracker. |  |
| Limits | What the record does not show. |  |
| Approvals | Who approved the plan, and the publication rule. |  |
