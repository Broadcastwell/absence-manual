# Which loan origination software does Claude recommend?

For a small mortgage broker, the recorded Claude list differed sharply from the community-bank list. nCino appeared in 21 of 30 loan-origination answers captured on 22 September 2026, but in none of the three answers to the small-broker question. ICE Mortgage Technology, Calyx and LendingPad each appeared in all three of those broker answers. The counts describe the captured lists, without assessing suitability for a lender.

## What this means for you

**Reasoned.** Start with your institution and the lending work in scope. A mortgage broker choosing an origination process has a different evaluation from a bank funding commercial loans. Read the relevant question before carrying a name into your research. The largest category total may be irrelevant to the task you are buying for.

For each retained system, identify the exact handoff you need to examine. That might involve an application record, a document exchange or a connection to an existing system. Ask the supplier for evidence covering that operation and its conditions. This study did not run those operations or verify a lender's compliance obligations.

Treat a broad supplier label carefully. ICE Mortgage Technology is the checked name in this table; its count does not resolve which particular product, version or deployment an answer meant. Keep the label used in the saved answer, then record any narrower product identification with its own source.

If an answer's product description conflicts with a dated primary document, preserve both passages before changing a public page. If the documentation is inconclusive, keep the finding unresolved. The useful correction is the precise fact you can establish, not an attempt to make a supplier appear in the next list.
