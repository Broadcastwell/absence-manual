# How does Claude web search work?

Claude web search retrieves material from the web to inform an answer and supplies citations when that search capability is used, according to Anthropic's guide read on 29 October 2026. Read the citation beside the particular claim. Our 22 September construction panel recorded Procore in 21 of 30 Claude answers.

## What we measured

**Reported.** [Anthropic's web-search guide](https://support.anthropic.com/en/articles/10684626-enabling-and-using-web-search), read on 29 October 2026, describes Claude invoking a search tool for relevant current information, processing sources and returning direct citations. It also describes web fetch for retrieving a supplied page when web search is enabled. The guide describes workspace and member controls, and separately notes that the new Claude experience has no web-search toggle: it searches when helpful.

**Measured.** The [September release](https://doi.org/10.5281/zenodo.22907695) records Procore's 21 naming appearances within Claude's 30 valid construction answers. The ten buyer questions and three repeats define that base. This figure counts the checked product name, not citations to Procore's own domain.

Those naming cells cannot establish which source Claude used for a claim or how it weighted that source.

## What this means for you

**Reasoned.** In a managed Claude workspace, read the current-experience note as well as Anthropic's workspace instructions. The guide documents an organisation-level permission and member control, but explicitly says the new Claude experience has no web-search toggle. If that is your interface, the missing toggle is consistent with the documented experience. Keep the experience and date with the saved answer.

If you supplied a direct URL, distinguish the web-fetch case described in the guide from asking Claude to discover sources. Reading a selected Procore page answers a different source question from finding independent pages for a construction comparison. Keep the selected address with that observation.

The construction question makes a visible difference in this Claude sample. Procore was named in zero of three answers for a small residential builder, and in all three for a mid-sized general contractor. Keep those exact buyer contexts with the citations you inspect, rather than using the pooled 21 as the answer to both questions.
