# Which dealership software does Claude recommend?

An independent lot and a dealer group should not inherit the same software list by assumption. Claude named CDK Global in 20 of 30 dealership answers captured on 22 September 2026 and DealerCenter in 16. DealerCenter appeared in all three answers about an independent used-car dealer, while the twelve-rooftop-group question named CDK Global in all three and DealerCenter in none. Those observations provide context for further checking, rather than a verdict on either system.

## What we measured

**Measured.** We used the Claude naming cells in the [September dealership collection](https://doi.org/10.5281/zenodo.22907695). Ten questions each had three scheduled answers; all 30 were valid. The collection includes independent dealers, small teams, powersports dealers, dealer groups and named comparisons. The capture date is 22 September 2026, and the release date is 23 September.

CDK Global's naming rate was 66.7 percent. The descriptive 95 percent Wilson interval, 48.8 to 80.8 percent, belongs to the captured panel. It is not an estimate of dealer adoption or a measured implementation outcome.

## What this means for you

**Reasoned.** Keep the dealership's operating context beside the question you are reading. A powersports store, an independent used-car lot and a group running several rooftops are different evaluation settings. Find the relevant answer record before asking a vendor to substantiate its claims.

Build your comparison around the work people will actually perform. If the answer describes inventory, a service process or a system connection, request evidence for that named function and product. Do not fill in an unmentioned feature simply because the supplier appeared frequently in the panel.

For an agency reporting this result, retain all checked names and the date. A list that drops zero rows can make the observed set look more comprehensive than it was. Also keep source citations separate: these Claude-specific counts measure naming, while the category's cited-domain records combine engines.
