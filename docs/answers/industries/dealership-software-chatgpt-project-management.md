# What can dealership software with ChatGPT do for project management?

Coordinate dealership follow-up through DealerAI's documented ChatGPT connection: its permitted actions include inventory lookups, staff-facing leads and Reach sequences. [The AI written RFP](https://doi.org/10.5281/zenodo.23271935), our published study, found a working-system-connections criterion in 6 of 150 dealership buyer answers captured on 22 September 2026. The named record and permission determine what that coordination covers.

**Reported.** DealerAI's connector guide, read on 29 October 2026, documents inventory, conversations, store information, lead creation and Reach follow-up, each subject to granted permissions. It scopes a connection to one store.

**Reasoned.** A request for a working integration and a documented list of allowed actions are distinct evidence. These public records do not test a live DealerAI connection or establish a complete project-planning workspace.

## What this means for you

One connection covers one store. DealerAI says a store administrator must enable the connector before a user connects it. A group operating several rooftops adds a separate connection for each selected store; the guide does not describe one shared project board spanning those connections.

Read and write permissions begin differently. Read permissions are selected by default; changing store details, creating leads and starting follow-up begin unselected. The documented Create leads action notifies staff and any connected CRM. Enroll contacts in sequences starts Reach follow-up. Those are concrete handoffs for your dealership, rather than a Gantt chart, dependency schedule or resource plan described by this source.

Store-profile permission also has a particular consequence. View store profile covers hours, staff, promotions and knowledge-base entries. Update store profile can change that material; the guide says saving or deleting knowledge-base content automatically retrains the assistant. Connected Apps lists the approving user and granted permissions. Turning off the store's connector cuts its connections, usually within about a minute.
