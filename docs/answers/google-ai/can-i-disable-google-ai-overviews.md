# Can I disable Google AI Overviews?

No permanent off switch for core AI Overviews is documented in Google's help, read on 29 October 2026. You can select the Web filter after a search to see text links without the Overview. An absent box is not evidence of an opt-out: in our residential property management capture on 22 September 2026, 2 of 30 scheduled Overview targets returned no Overview. We did not test a setting change.

## What we measured

**Measured.** 22 September 2026; release 2026-09.

The September Absence Index scheduled ten property-management questions, three times each, for this Google surface. Its published exclusions identify two no-Overview returns: the third repeat of the Buildium versus AppFolio question and the first repeat of the question about choosing property-management software. Those two returns are excluded from vendor naming rates. They are not answers in which every vendor received a zero.

The [published release and method](https://doi.org/10.5281/zenodo.22907695) preserve the retained engine bases and the exclusion reasons. This was a set of recorded searches, not an experiment with account preferences, browser extensions or Labs settings. It cannot tell you whether a particular workaround stays in effect across later searches.

**Reported.** Google's [consumer help](https://support.google.com/websearch/answer/14901683) supplies the control information. It distinguishes a core Search feature from the optional AI experiments in Labs. The same help warns that Search settings are being updated, so the instructions may differ from the interface you see.

## What this means for you

**Reasoned.** Choose Web for that search. Google's description says this view removes search features such as Overviews and shows text-based links. It does not describe an account-wide preference that permanently disables the feature. If your next search opens in another view, the previous Web result is not proof that the preference was saved.

The Labs switch has a narrower purpose. Turning off AI in Search there opts out of its experiments; Google's separate statement about core Overviews still applies. A guide that points only to the Labs toggle has not established that ordinary Overviews will disappear.

Keep the September example in mind when checking a claimed fix. One property-management query failed to produce an Overview on one repeat while other repeats had valid responses. Seeing no box once cannot distinguish a working control from ordinary variation in what Google returned. To judge an instruction, ask whether it changes the selected search view or an experimental feature. Those are the two documented choices here.
