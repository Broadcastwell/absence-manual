# How do Google AI Overviews and generative UI relate?

Generative UI is a way Google can present an AI answer as an interactive visual or tool inside Search. Google described it in Overviews on 19 August 2026; our [September Index](https://doi.org/10.5281/zenodo.22907695) retained 415 Overview text-answer records from 420 targets on 22 and 23 September 2026, a different unit from counting interactive widgets.

## What we measured

**Reported.** Google's [19 August announcement](https://blog.google/products-and-platforms/products/search/back-to-school-study-tools/), read on 29 October 2026, illustrates an interactive pH scale in an Overview. A follow-up asking to plot citrus fruits moves into AI Mode for a more specific generated experience. The article says generative UI had launched globally in English in Mode and had begun rolling out in Overviews.

**Measured.** The September Index collected the named vendors and cited sources in software-buyer answers. Fourteen categories, ten questions and three repeats supplied 420 scheduled Overview targets; 415 were retained. That source preserves answer text and collection outcomes, rather than an inventory of the controls, simulations or visual states rendered on the results page.

**Reasoned.** The two records answer different questions: whether an Overview named a vendor, and how Google presented a response. Our text collection cannot establish how often interactive UI appeared or whether a widget's displayed controls worked.

## What this means for you

For you as a reader, the pH example explains the distinction without inventing another engine. An Overview can contain an interactive visual; generative UI describes that presentation capability. The follow-up into Mode changes the Search surface, even when the topic remains the pH scale.

Keep the interaction visible. A text extract of a pH answer can preserve the labels and explanation while losing what changes when a slider moves. If the claim being checked concerns that interaction, the static answer text is insufficient evidence for the claimed behavior. A screenshot and the source answer also serve different purposes: one shows the displayed state, while the other preserves the wording being counted.

For software visibility reporting, retain the name and citation rules from the September Index when comparing with its figures. Do not add every text label inside a generated tool as though it were another independently collected buyer answer. Specify whether a reported observation concerns the Overview, its interactive component or the subsequent Mode exchange; those units can occur in one session without being interchangeable.
