# How many software vendors does ChatGPT name in an answer?

Our fourteen-category sample averaged 3.56 checked-vendor names per valid ChatGPT answer captured on 22 September 2026. That is 1,496 checked-name appearances divided by 420 answers. It counts each checked vendor at most once within an answer, without counting every software name on the market or assigning a recommendation probability.

## What we measured

**Measured.** The [September Index method](https://doi.org/10.5281/zenodo.22907695) fixed ten buyer questions per category and three scheduled ChatGPT runs. Each of the fourteen ChatGPT category panels supplied thirty valid answers. The checked vendor set was defined for each category; the release was published on 23 September 2026.

Adding the category appearances gives 1,496, while the answer bases sum to 420. Their quotient is 3.5619 before rounding. A vendor can contribute appearances in several answers, and several checked vendors can contribute to one answer. This is a descriptive mean count, rather than a binary naming percentage, so a Wilson interval for a single company's rate is a different calculation.

## What this means for you

Read the unit before using the average. “Checked names per answer” differs from “share of answers naming my company”. A single answer can have more than one checked name, while a given vendor's naming event remains either present or absent in that answer.

The mean does not tell you that every answer contained three or four names. Nor does it include unlisted vendors just because an engine may have mentioned them. Interpret it within the fourteen fixed category panels, not as a universal shortlist length.

For a practical product question, return to its category and question records. Their counts preserve the buyer need that an overall mean necessarily combines. The study does not establish how many names a future ChatGPT response will return.
