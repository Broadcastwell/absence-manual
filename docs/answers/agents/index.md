# Agents answers

What assistants found, understood and reached on public software websites.

These 7 answers use dated Broadcastwell findings. Each page identifies its question, figure and source; a count in an answer does not establish product quality or a completed sale.

## Connections and public browsing

[How does an AI connector differ from browsing a website?](how-does-an-ai-connector-differ-from-browsing-a-website.md)

Browsing and connectors expose different routes: the Agent Gap study found pages in 210 tasks and reached 163 handoffs.

## Reading public pages

[What can an AI assistant learn from a software website?](what-can-an-ai-assistant-learn-from-a-software-website.md)

The Agent Gap Describe task found 70 vendor pages and recorded 69 correct results on 6 October 2026; it did not test the products.

## Pricing paths

[Can an AI assistant find a software pricing page?](can-an-ai-assistant-find-a-software-pricing-page.md)

In Agent Gap, 70 of 70 pricing pages were found, 67 results were correct and 52 reached the task endpoint on 6 October 2026.

[How can a software website make its public pricing path clearer?](how-can-a-software-website-make-its-public-pricing-path-clearer.md)

Make the price, qualification and route explicit: Agent Gap reached 52 of 70 pricing-task endpoints on 6 October 2026.

## Demo paths

[How far can an AI assistant get along a software demo path?](how-far-can-an-ai-assistant-get-along-a-software-demo-path.md)

The Agent Gap demo task recorded 70 correct results but 44 reached endpoints from 70 sessions on 6 October 2026.

## Evidence boundaries

[Does finding a page prove an AI assistant understood it?](does-finding-a-page-prove-an-ai-assistant-understood-it.md)

Finding is not correctness: Agent Gap found pages in 210 initial sessions, with 206 correct, 3 incorrect and 1 unscored result.

[Does an AI handoff mean a software purchase was completed?](does-an-ai-handoff-mean-a-software-purchase-was-completed.md)

A handoff is not a sale: Agent Gap reached 163 endpoints in 210 initial website tasks on 6 October 2026.
