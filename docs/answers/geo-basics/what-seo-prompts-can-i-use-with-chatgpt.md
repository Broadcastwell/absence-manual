# What SEO prompts can I use with ChatGPT?

Ask ChatGPT to separate the product claim, its billing qualifiers and the dated reference before using the material in an SEO comparison. Our [Wrong About You study](https://doi.org/10.5281/zenodo.23270124) found 2 wrong statements among 41 Jobber statements, using 22 September 2026 captures and an 8 October reference check. The prompts below are proposed writing aids grounded in that example, not prompts we ran as a new test.

## What we measured

**Measured.** The [published statement-review method](https://doi.org/10.5281/zenodo.23270124) preserves two different Jobber pricing propositions. The Core starting-price statement recurs in two Claude returns; an Overview return contains the other pricing-range claim. The forty-one-statement row also includes twenty-nine true and ten unverifiable entries, with no stale entries. Team review: in progress. The dataset does not test whether these proposed prompts improve accuracy or SEO performance.

**Reasoned.** The retained plan name, billing language, capture date and pricing-page reference give a proposed research prompt specific fields to ask about. A missing field can remain unknown rather than being supplied from the generated answer's confidence.

## What this means for you

Begin with the original sentence. One proposed prompt is: "Extract the exact Jobber Core price claim from this retained answer, including any words about the billing period and included users." That task concerns the Core entry, rather than every product named elsewhere in the HVAC answer.

For the source comparison, a proposed prompt is: "Compare that Core claim with the retained 8 October pricing-page extract. Separate the monthly display from the annually billed amount, and identify the user allowance shown in the extract." The dated extract is the input; this wording does not assert that the October terms are still current.

Keep the dates explicit. A proposed correction-writing prompt is: "Draft a note that identifies the 22 September answer and the 8 October reference separately. Explain only the disagreement those retained records support." The other Jobber entry concerns a range in an Overview answer, so it needs its own claim text rather than silently inheriting the Core note.

For a report draft, the proposed instruction can be: "Count the two repeated Claude observations as one Core statement, and preserve the ten unverifiable statements as a separate class."
