# How can I track brand visibility in Claude?

2,039 checked-name appearances across 420 Claude answers were recorded in our [22 September 2026 Index capture](https://doi.org/10.5281/zenodo.22907695). To track brand visibility in Claude, preserve the exact buyer question and response, then count the checked brand under one stated alias rule; appearances across several brands are not your brand’s answer share.

## What we measured

**Measured.** The [September Index method](https://doi.org/10.5281/zenodo.22907695) fixes ten questions in each of fourteen software categories and repeats them three times per engine. Summing Claude's checked-vendor counts gives 2,039 appearances across its 420 answers. Several names can occur in one response, so the numerator is a vendor/answer event rather than an answer count.

**Reported.** Anthropic's [consumer web-search help](https://support.claude.com/en/articles/10684626-enable-and-use-web-search), read on 29 October 2026, describes citations when Claude searches. It distinguishes the older chat toggle from the newer experience that searches when useful, and identifies workspace-level controls for Team and Enterprise accounts.

**Reasoned.** That help page explains a Search capability; it does not establish that every captured Claude response used web search. Our collected naming counts cannot establish the traffic or sales received by a named vendor.

## What this means for you

Start with the question. For the Index's mid-sized-general-contractor question, Claude names Sage 300 CRE in all three repeats, whereas ChatGPT names it in none. An engine label therefore belongs with the result even when both rows use the same buyer wording and repeat base.

Claude's checked set also includes named aliases. The construction record binds Procore Technologies and PCOR to Procore; these strings should follow the published matching rule rather than become additional vendors in a report. A later manual review can inspect the retained wording without changing what the original alias rule counted.

Keep Claude's cited source separate from that name match. Anthropic's help describes a search indicator and linked sources, which are evidence a reader can inspect when that Search feature runs. The Index's engine-presence fields instead record named-vendor counts. A traditional ranking position is not one of those fields, and a link to a source is not an additional instance of the vendor's name.
