# How should the report show visits?

If you are reporting visits, state the reporting period, what counted as a visit and the source evidence received. Our [22 September 2026 Index](https://doi.org/10.5281/zenodo.22907695) recorded Procore naming alongside an own-domain citation in 30 of 150 construction-software answers. That figure belongs to an answer-observation row; it cannot supply the visit count or visit definition in a traffic report.

## What we measured

**Measured.** The [original construction CSV and release](https://doi.org/10.5281/zenodo.22907695) combine ten buyer questions, three returns and five engines. Procore's concurrent naming-and-own-domain-citation count uses a base of 150 answers. Its recorded own-domain sources include procore.com and learn.procore.com. This count contains no visitor or session record.

**Reported.** The [AI Source Standard's visits section](https://docs.broadcastwell.com/ai-source-standard/#4-analytics) asks for the period and visit definition, separate source labels and buyer self-reports, and disclosure of changes affecting period comparisons. Google's [AI features guide](https://developers.google.com/search/docs/appearance/ai-features), read on 29 October 2026, says traffic from its AI features is included in Search Console's overall Web search reporting.

**Reasoned.** A report can show the dated Procore citation observation as context, while the visit row remains tied to its own traffic record and the scope of the tool reporting it.

## What this means for you

Label that column Web. For Google's search figures, the published Web reporting scope matters when someone asks for an AI-only visit total. A Web total containing AI-feature traffic is not automatically an isolated Mode or Overview count. The Procore source rows offer a parallel unit check: two named own-domain hosts can occur in the evidence, while the published numerator still counts answers rather than URL requests.
