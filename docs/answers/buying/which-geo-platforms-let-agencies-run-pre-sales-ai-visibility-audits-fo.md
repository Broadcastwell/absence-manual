# Which GEO platforms let agencies run pre-sales AI visibility audits for prospects?

OtterlyAI documents temporary Workspaces for proposals, so it offers a named route for agencies preparing prospect audits. Scope the output before treating a visibility chart as a fact-checked sales report: Wrong About You marked two of 57 Procore statements wrong in answers captured on 22 September 2026, against vendor evidence read on 8 October.

## What we measured

**Measured.** The [Wrong About You method and records](https://doi.org/10.5281/zenodo.23270124) separate 38 true, two wrong, zero stale and 17 unverifiable Procore statements. One wrong flag concerns whether a pricing page exists; the other concerns charging for additional users. They would support different proposed corrections. This study did not test OtterlyAI, and team review of the two flags remains in progress.

**Reported.** OtterlyAI's [27 February 2026 Workspace guide](https://help.otterly.ai/what-are-workspaces-and-how-can-they-help-you-stay-organized-across-clients), read on 29 October, expressly describes temporary Workspaces for proposals. Administrators assign prompts and GEO Audits to each Workspace under a single subscription. The guide names Standard, Premium and Custom Enterprise plans. Team members can join multiple Workspaces, while clients see the reports and data relevant to them.

Its [5 August 2026 multi-client guide](https://help.otterly.ai/can-i-manage-multiple-brands-under-one-account), read the same day, distinguishes competitors within one Brand Report from separate client Workspaces. Prompts come from the plan's shared pool; the administrator decides how many go to each report or Workspace. Reusing a prompt across reports does not require buying that prompt twice.

## What this means for you

**Reasoned.** For a prospect pitch, a temporary Workspace provides a documented place to separate that company's proposed research from existing client reports. Decide whether colleagues alone will read the proposal or whether the prospect will receive access. OtterlyAI describes team assignment and client-specific visibility; those access choices belong in the proposal's delivery scope rather than being assumed from the word audit.

Set the prompt allocation first. A Workspace can separate the prospect's material without creating an independent prompt allowance. In the proposal, name the questions assigned to that prospect and the resource allocation you are taking from the shared plan. The provider's guide permits those allocations to change; it does not make every new prospect a separate subscription or supply an unlimited research budget.

The Procore flags show why the sales deliverable needs a separate factual-review decision. An assertion that a pricing page is missing would suggest creating content, but the saved reference already contains that page. A per-user assertion requires a different source passage. If you sell a fact-checked prospect report, specify that comparison with the provider's evidence before proposing either change. The 17 unverifiable statements would not justify 17 asserted errors in the pitch.
