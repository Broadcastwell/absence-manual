# What should I ask a GEO provider about MCP or API access?

Ask which records you can read, which actions you can request and what permission each needs. In the Agent Gap collection on 6 October 2026, the assistant found a destination in all 210 initial task sessions but reached a handoff in 163. Access to a tool or page is not evidence that a whole task, integration or purchase works.

## What we measured

**Measured.** The [Agent Gap study method](https://doi.org/10.5281/zenodo.23197560) used ChatGPT Work for three public website tasks across 70 software vendors: describe the product, find pricing and follow a demo path. The 210 initial sessions are separate from 30 preselected repeats. Destination correctness was 206 correct, three incorrect and one unscored; 163 reached the task's handoff. No authenticated MCP or API integration was tested.

**Reported.** The [official MCP architecture](https://modelcontextprotocol.io/docs/2026-07-28/learn/architecture), read on 28 October 2026, describes a protocol for context exchange between clients and servers, with tools and resources among its interfaces. That definition does not establish any GEO supplier's implementation or its allowed actions.

## What this means for you

**Reasoned.** Put a small acceptance example in the procurement scope. Name the record you expect back, its date fields and identifiers, the account boundary and whether access is read-only. If actions are available, ask which ones require approval and how a mistaken request is reported or reversed.

Keep the interface promise separate from the evidence promise. An endpoint may return data successfully while the returned record lacks the answer, source or valid base needed for your decision. Ask for a sample response and a clear explanation of missing, stale and failed observations. A page-browsing demonstration cannot substitute for that interface-specific evidence.

- **For a tool buyer:** request the exact documented data and permission scope before enabling access.
- **For an agency:** check how one client's records are kept apart from another's.
- **For a vendor:** state whether the demonstration covers browsing, record retrieval or a permitted action.
