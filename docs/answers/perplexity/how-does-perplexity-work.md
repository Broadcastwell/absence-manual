# How does Perplexity work?

Perplexity describes its search experience as finding web sources and producing an answer with source links; its current Pro Search guide explains a deeper search option within that experience. Our construction-software capture on 22 September 2026 named Procore in 21 of 30 Perplexity answers. That observation shows what appeared in our questions, while the provider's documentation explains the reported search feature.

## What we measured

**Reported.** The [Perplexity Pro Search guide](https://www.perplexity.ai/help-center/en/articles/10352903-what-is-pro-search), marked modified 26 October 2026 and read on 29 October, describes searching sources, synthesising information and citing references. It says Pro Search is no longer a separate toggle: Search uses it automatically within the plan's allowance. The guide distinguishes this from other modes; its current feature description is not a label for our earlier capture.

**Measured.** In the [September Index](https://doi.org/10.5281/zenodo.22907695), ten construction buyer questions supplied three Perplexity runs each. All 30 answers were valid and 21 named Procore. The engine-presence field records naming, not the number of source links and not the quality of the product.

The September count cannot reveal Perplexity's source-selection weights or establish which current search mode produced those earlier answers.

## What this means for you

**Reasoned.** Read the Search distinction. It describes standard search as a quick answer from a smaller source set and Pro Search as deeper synthesis with more source links. That is Perplexity's explanation of the feature, not a measured difference between modes in our construction panel. The Procore count comes from the retained engine answers, with no mode comparison attached.

For a construction purchase, the Procore cells show why the project context matters. Perplexity named it in all three mid-sized general-contractor answers, but none of the three small residential-builder answers. The 21-of-30 category count combines those contexts. Read the relevant buyer record before treating the total as a shortlist for your job.

The current guide also matters when explaining the interface to a colleague. Instructions to find an old Pro Search toggle would send that reader looking for a control the provider now says is integrated into Search. State the guide's date and keep that explanation distinct from the September observations.

Procore also had zero names in the three Perplexity answers about an owner managing capital projects. That is an observed omission for a checked vendor, not evidence of a blocked crawler or a product limitation. A question about an owner does different work from the mid-sized contractor question even when both sit in construction software.

The October guide's automatic Pro Search description belongs in an explanation of the current interface. Our September cells do not record that current setting. If you are explaining the 21 Procore names to a client, label them as the dated Perplexity observations rather than retroactively calling them an October Pro Search result.
